# 巨物场景生成 SKILL V2.0 · 巨物美学优化版

> **Giant Scale Scene Director System**
> 巨物场景自动导演系统 —— 让 AI 真正画出"大到超出认知"的巨物。

## 这是什么

一个用于 AI 图像 / 视频生成的**巨物场景提示词工程 SKILL**。

它的核心任务不是"生成一个很大的怪物"，而是：

> 通过人物、环境、空间、镜头和局部展示，让观众真正感受到——
> **"这个东西巨大到超出正常认知。"**

## 核心能力

- **巨物类型识别**：生物型 / 人形 / 自然融合型 / 遗迹文明型 / 不可测型
- **尺度等级系统 S1-S7**（大型 → 不可测级）：
  拒绝只依赖"万米、百万米"数字，改用**视觉尺度 + 环境关系**
- **尺度锁定系统**：强制人物 / 建筑 / 山峰参照，防止 AI 把巨物画小
- **巨物展示完整度控制**：完整 → 部分超出画面 → 环境遮挡 → 局部展示
- **镜头导演系统**：建立尺度 → 人物仰望 → 巨物局部 → 环境反应 → 最终大全景
- **5 种构图模式**：脚下仰视 / 天空横跨 / 山岳融合 / 巨大局部 / 环境经过
- **6 大风格自动决策**：唯美 / 神秘 / 史诗 / 恐怖 / 神圣 / 东方神话
- **环境互动系统**：空气 / 地面 / 水面 / 生物，至少 2 项
- **构图禁止规则**：禁止普通角色展示、背景贴图、无空间层级等
- **标准输出模板 + 最终质量检查清单**

## 附带案例

- 唯美天空巨鲸（S5）
- 天空巨鹿（S5）
- 海中不可测巨物（S7）

## 使用方式

用户只需要输入简单描述（例如"巨大的鲸鱼"），SKILL 自动补全：

```
巨物类型 → 尺度等级 → 风格 → 人物参照 → 环境参照
→ 空间关系 → 展示完整度 → 姿态 → 环境互动
→ 镜头 → 尺度锁定
```

输出可直接用于 AI 图像 / 视频生成的完整提示词。
